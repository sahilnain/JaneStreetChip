# Instruction Set

```
Basic instructions:
LOAD    Rd, imm        ; Rd = imm
DEC     Rd             ; Rd = Rd - 1
SHR     Rd             ; shift Rd right by 1, LSB goes into carry bit C
AND     Rd, imm        ; Rd = Rd & imm
OR      Rd, Rs         ; Rd = Rd | Rs
BZ   Rd, label         ; branch if Rd == 0
BNZ  Rd, label         ; branch if Rd != 0
BC   label             ; branch if carry bit set
JMP  label
CALL label
RET

Protocol instructions:
SET_PIN pin, val       ; drive pin to 0 or 1
READ_PIN pin, Rd       ; sample pin into Rd
RELEASE_PIN pin        ; stop driving (open-drain — let pull-up/down decide)

```

# I2C Write Byte (with START, STOP, ACK, clock stretching)

Byte to send in `R0`. SDA/SCL are open-drain: driving `0` pulls the line low,
`RELEASE_PIN` lets the external pull-up win (i.e. logical `1`).

1. The program here does not take into account multi-slave for now. TODO: add multi-slave feature. Should be easy, 
CS bit, we can set a register that control IO pins.
2. If we are able to alter the clock frequency of the emulator, to match 
the SPI clock rate, then we can get away with clk_rise in this program.
3. Need to adapt this if the emulator is a slave.


```
; START condition: SDA falls while SCL high
        RELEASE_PIN SCL     // instead of release pin, we should have a STOP_DRIVING_PIN command and pair this with PULL_LOW/PULL_HIGH command instead of SET_PIN.
        RELEASE_PIN SDA
        SET_PIN     SDA, 0
        SET_PIN     SCL, 0

        LOAD    R2, 8
i2c_loop:
        LOAD    R3, R0         ; might be redundant, can save the result of AND (next instruction) in another register
        AND     R3, 0x80
        BZ      R3, sda_low
        RELEASE_PIN SDA        ; '1' = let pull-up win
        JMP     clock_it
sda_low:
        SET_PIN SDA, 0
clock_it:
        RELEASE_PIN SCL        ; clock high (check for stretching below)

stretch_check: ; Although the clock signal is always generated by the current bus controller; some peripheral devices may force the clock low at times to delay the controller sending more data
        READ_PIN SCL, R4
        BZ      R4, stretch_check   ; peripheral holding SCL low = wait

        SET_PIN SCL, 0
        SHR     R0
        DEC     R2
        BNZ     R2, i2c_loop

; ACK check
        RELEASE_PIN SDA
        RELEASE_PIN SCL
stretch_check2:
        READ_PIN SCL, R4
        BZ      R4, stretch_check2
        READ_PIN SDA, R5       ; 0 = ACK, 1 = NACK
        SET_PIN SCL, 0

; STOP condition: SDA rises while SCL high
        SET_PIN     SDA, 0
        RELEASE_PIN SCL
        RELEASE_PIN SDA
```
